# Recruit_Filter_Json  
　求人フィルターで使用可能なJsonファイル。  
　各Jsonは重複して読み込み可能。  
  
## 中身  
  
＊＝準備中のもの  
  
・＊AIサムネイル使用  
・＊未経験からエンジニア系  
・＊未経験からデザイナー系  
・＊モクモク/軽作業系  
・＊携帯販売/スマホ教室系  
・＊派遣会社  
・＊支給/勤務着が半袖

このリストに掲載されているから危険という意味ではない。

このリストを元に投資判断や、就職活動の最終決断を行うことはおやめください。

これらのリストは順不同であり、掲載順に特別な意味は一切無く、示唆する目的もない。  
  
  
## 注意事項  コミットを行う方は必ずお読みください  
  
事件事故などを掲載基準に含めない。  
給与額・現職者・退職者からの評価を掲載基準に含めない。  
株価や公式・非公式発表を掲載基準に含めない。  
株式会社・合同会社・有限会社・外資などの企業形態を掲載基準に含めない。  
アルバイト・パート・業務委託・フリーランス・正社員・派遣・紹介予定派遣など、個別の雇用形態を掲載基準に含めない。  
勤務地や採用ポジションを掲載基準に含めない。  
個人的な感情や体験談を掲載基準に含めない。  
  
偽装求人・闇バイトはリスト化しない。（事実確認が困難で、公共の利益を個人的なリスクが上回るため）  
プルリクエストや、イシューに各企業への風評を書かない。  
リポジトリに関わるすべての人は、中立的な立場で公共の利益のためにリストを更新する。  
  
特定企業・業種・店舗・人物など、そしてこれらに限定せず、他者への風評を不必要に流布する旨のコメント等は内容に関わらず予告無く削除します。  
悪質な内容、行為を頻発するユーザーはブロックし、場合によっては法的処置を検討します。  
各企業への内外からの評価を元にしたリストではなく、属性分類に基づいたリストであろうと努めてください。  

このリポジトリへのコメントなどはシステム上自由に即座に行うことができ、それらすべてをオーナーが検閲することはリソース上できません。  
よって、これらのコメントは掲載されていようとオーナーやリポジトリの見解とは一致せず、それを支持するものでもありません。  
  
  
## コミットルール  
  
最終マージはオーナーが行います。  
Jsonファイル内にコメントを記述することは禁止。  
コミットには掲載理由を記述してください。（例：hogehoge.com/{campany}/{recruit}にてAIサムネイルを使用しているため）  
注意事項をよく読み、掲載理由は絶対に注意事項に抵触しないでください。  
掲載不可の場合はマージを拒否し、理由の開示義務は持たないものとします。  
  
追加する社名はその一社のみを特定できる形でコミットする。表記揺れが考えられる場合はそれぞれ記述し、一つのコミットにまとめる。  
　良い例：hogehogeサービスグループ㈱  
　　　　　株式会社もげもげフード  
　　　　　㈱もげもげフード　埼玉事業所  
  
　悪い例：サービス　　　//対象が広すぎる  
　　　　　スタッフ　　　//複数社名がヒットする  
　　　　　㈱スタッフ　　//㈱があるが短すぎる  
  
本リポジトリは求人フィルターで使用できるリストであり、拡張機能（求人フィルター）本体へのコミットを受け付けるリポジトリではない。  
なお、ほか拡張機能・アプリなどツール類への流用は制限しないが、動作保証もせず、ほかツールへ対応させるためのコミットも受け付けない。  
  
  
## 削除要請  
  
削除要請は理由とともにプルリクエストから行ってください。DM・メールなどでは一切受け付けておりません。  
社内担当者・当事者の場合はその旨も併記してください。  
本リポジトリの掲載と保守は公共の利益のため、一切の悪意や風評の流布の意図なく、善良な民間の手で行われているため、特別な理由なき削除要請はお断りする場合があります、あらかじめご了承ください。  
削除要請あるいはリポジトリオーナー判断により削除した社名は再掲載を防ぐため、リポジトリ外の特定のリストに保存される可能性があります。公開はされません。  
削除要請のプルリクエストを送信した時点でこれらに同意したものとみなします。  


## 環境メモ  
  
リポジトリへのプッシュを起点にCloudFlare Workersにデプロイされる。  
リストの取得はWorkersから、リストの追加時に一度だけ行われる。  
リストを更新する場合は一度リストを無効化した後再度有効化することで可能。    

### デプロイ設定

ビルド不要（Workersの静的アセット配信でリポジトリ直下のJSONをそのまま返す）。  
Cloudflare Workers（Git連携）のBuild commandは空欄のままでよい。  
ローカルからは `npm install` の後 `npm run deploy` でデプロイ可能。
